# 🎮 «КОНТАКТ!» (Есть контакт!) — Онлайн Вечеринка

Современное многопользовательское веб-приложение для популярной интеллектуальной словесной игры **«Контакт»**.
Приложение полностью **serverless**: работает на базе React (Vite) + Tailwind CSS + Firebase Realtime Database и может бесплатно хоститься на **Vercel** или **GitHub Pages**.

---

## 🌟 Ключевые возможности

- ⚡ **Realtime-синхронизация:** мгновенное обновление комнат через Firebase Realtime Database.
- 🔄 **Встроенный локальный мультиплеер (Zero-Config Demo):** если ключи Firebase ещё не указаны, игра автоматически включает локальную синхронизацию (`BroadcastChannel`), позволяя играть между двумя вкладками одного браузера без предварительной настройки базы данных!
- 👑 **Ролевая модель:** Ведущий (загадывает слово, видит скрытые буквы, отбивает намёки «Это не...») и Игроки (задают ассоциации, жмут кнопку «ЕСТЬ КОНТАКТ!», сверяют слова).
- ⏱️ **Синхронизированный 10-секундный таймер:** визуальный прогресс и звуковые тики с переходом в режим сверки слов или отбития.
- 🔒 **Конфиденциальная сверка слов:** автор и партнер тайно вводят задуманные слова; при совпадении ведущему автоматически открывается следующая буква.
- 🎯 **Прямая угадайка:** возможность в любой момент назвать всё тайное слово целиком.
- 🔊 **Web Audio API:** звуковые эффекты (тики таймера, сигнал тревоги при контакте, звук отбития щитом, праздничные фанфары) синтезируются браузером на лету без внешних mp3-файлов.
- 📱 **Mobile-First адаптивность:** комфортная игра со смартфонов, планшетов и десктопов.
- 📜 **История событий раунда:** подробная лента всех намёков, отбитий и открытых букв.
- ⚙️ **Встроенный интерфейс настройки Firebase:** вставка конфигурации прямо из интерфейса без пересборки проекта.

## 🚀 Быстрый старт локально

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск сервера разработки
```bash
npm run dev
```
Откройте [http://127.0.0.1:3000](http://127.0.0.1:3000) в двух разных вкладках браузера. В одной выберите роль «Ведущий», в другой — «Игрок». Вы сможете сыграть полноценную партию прямо сейчас!

### 3. Сборка для продакшена
```bash
npm run build
```

## 🔥 Пошаговое руководство: Настройка бесплатной базы Firebase Realtime Database

Чтобы в игру могли играть друзья из разных городов и устройств через интернет:

### Шаг 1: Создание проекта Firebase
1. Перейдите в [Firebase Console](https://console.firebase.google.com/) и войдите с аккаунтом Google.
2. Нажмите **«Add project»** (Добавить проект).
3. Введите название проекта (например, `contact-party-game`).
4. Отключите Google Analytics (не требуется для игры) и нажмите **«Create project»**.

### Шаг 2: Создание базы данных Realtime Database
1. В левом меню консоли выберите **Build** ➔ **Realtime Database**.
2. Нажмите кнопку **«Create Database»** (Создать базу данных).
3. Выберите ближайший регион (например, `Belgium (europe-west1)` или `United States (us-central1)`).
4. На шаге правил безопасности выберите **«Start in test mode»** (Начать в тестовом режиме) и нажмите **Enable**.

### Шаг 3: Настройка правил безопасности (`rules.json`)
1. Во вкладке **Rules** (Правила) вашей Realtime Database замените содержимое на:
```json
{
  "rules": {
    "rooms": {
      "$roomId": {
        ".read": true,
        ".write": true,
        ".indexOn": ["createdAt", "status"]
      }
    }
  }
}
```
2. Нажмите **Publish** (Опубликовать).

### Шаг 4: Получение конфигурации веб-приложения
1. Нажмите на иконку шестерёнки в левом верхнем углу (рядом с Project Overview) ➔ **Project settings**.
2. Прокрутите вниз до блока **Your apps** и нажмите на круглую иконку веб-приложения `</>`.
3. Задайте имя приложению (например, `Contact Web`) и нажмите **Register app**.
4. Скопируйте объект `firebaseConfig`, содержащий:
   - `apiKey`
   - `databaseURL` (обратите внимание, чтобы поле `databaseURL` присутствовало)
   - `projectId`

### Шаг 5: Подключение конфигурации к игре
Есть 2 удобных способа:
- **Способ А (Без кода прямо в браузере):** Нажмите на иконку шестерёнки/огонька в шапке игры и вставьте скопированный JSON в поле «Быстрая вставка». Нажмите «Заполнить» и «Сохранить».
- **Способ Б (Через `.env`):** Создайте файл `.env.local` в корне проекта по образцу `.env.example`:
  ```env
  VITE_FIREBASE_API_KEY="AIzaSy..."
  VITE_FIREBASE_DATABASE_URL="https://your-app-default-rtdb.firebaseio.com"
  VITE_FIREBASE_PROJECT_ID="your-app"
  ```

## ☁️ Деплой на Vercel (бесплатный хостинг)

### Вариант 1: Через GitHub и Vercel Dashboard
1. Создайте репозиторий на GitHub и отправьте код проекта:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of Contact party game"
   git branch -M main
   git remote add origin https://github.com/ВАШ_АККАУНТ/contact-game.git
   git push -u origin main
   ```
2. Перейдите на [vercel.com](https://vercel.com/) и войдите через GitHub.
3. Нажмите **Add New...** ➔ **Project**.
4. Выберите репозиторий `contact-game`.
5. В разделе **Environment Variables** добавьте переменные из шага 5 (`VITE_FIREBASE_API_KEY`, `VITE_FIREBASE_DATABASE_URL`, `VITE_FIREBASE_PROJECT_ID`).
6. Нажмите **Deploy**.
7. Приложение развернется за 30 секунд и получит бесплатный SSL-домен вида `https://contact-game.vercel.app`!

## 📖 Краткие правила игры «Контакт»

1. **Ведущий** загадывает слово (например, **КОМПЬЮТЕР**). В начале игры открыта первая буква: **К...**.
2. **Игроки** придумывают намёки на другие слова, начинающиеся на открытые буквы (например: *«Это не то, чем копают огород?»* — слово на К: *Культиватор*).
3. **«Контакт!»:** Если другой игрок понял намёк, он нажимает большую кнопку «ЕСТЬ КОНТАКТ!». Запускается 10-секундный таймер.
4. **Отбитие:** До истечения таймера ведущий может отбить намёк: *«Это не Культиватор!»*. Если ведущий успел, контакт срывается.
5. **Сверка слов:** Если ведущий не успел отбить, автор вопроса и нажавший «Контакт» тайно вводят свои слова. Если они совпали, открывается следующая буква слова ведущего!
6. **Победа:** Игроки побеждают, когда открыты все буквы слова ведущего или названо всё слово целиком!
